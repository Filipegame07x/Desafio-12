# Desafio 12 - GamerTeam Manager 🎮

Projeto desenvolvido para gerenciamento de equipe gamer, praticando os conceitos de **Arrays**, **Objetos**, **Loops (`for` / `while`)** e **Funções** em JavaScript.

## 🚀 Funcionalidades

1. **Cadastrar Jogador**: Cadastra novos jogadores com nome, função e pontuação inicial.
2. **Deletar Jogador**: Remove um jogador da equipe pelo nome.
3. **Mostrar Equipe**: Exibe a lista completa de jogadores cadastrados e suas informações.
4. **Calcular Média da Equipe**: Calcula e exibe a média de pontos de todos os jogadores.
5. **Atualizar Pontuação**: Localiza um jogador pelo nome e soma novos pontos obtidos na partida ao seu ranking.
6. **Sair**: Encerra o sistema.

## 💻 Como Executar

1. Clone o repositório ou baixe os arquivos.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o programa:
   ```bash
   node gamerTeam.js
   ```
